## Review terhadap kebutuhan dan data

- Tabel `site_settings` tetap menggunakan seed bersumber proposal dengan status `draft` dan `is_sample=false`; tidak ada angka atau isi desa baru yang dibuat.
- Status `published` hanya dapat dibaca publik melalui RLS. Form admin memperlihatkan pilihan publikasi secara eksplisit dan peringatan verifikasi kecamatan serta izin kontak.
- Server Action pengaturan memanggil `requireAdmin()` sebelum validasi/penulisan. Proxy melakukan redirect sesi anonim, sementara layout server memeriksa membership admin aktif.
- Perubahan data memperbarui cache bertag `site-settings` dan me-revalidate layout publik. Public route menggunakan ISR 5 menit.
- Detail Supabase, migration, dan hasil advisor ada pada bagian Task 0.5 di `docs/PROGRESS.md`.

## Catatan lingkungan dan batas verifikasi

`npm run test:e2e` tidak dapat meluncurkan Chromium Playwright pada mesin ini. Pemeriksaan alternatif read-only melalui Playwright API dengan executable Microsoft Edge yang terpasang berhasil pada 360/768/1280 px, termasuk skip link, menu mobile, reduced motion, landmark `main`, dan redirect anonim. Alur submit login, penolakan akun non-admin, penyimpanan pengaturan, serta publikasi belum diuji karena akun resmi belum dibuat. Jangan membuat akun atau menerbitkan seed tanpa persetujuan pihak desa.
